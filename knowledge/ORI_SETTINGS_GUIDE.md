# ORI Settings Guide — 3.3

Settings are compact category pages; the main Settings page has no vertical scroll bar.

- **AI & Profile:** one Google AI Studio API key, test/save, preferred name, language, conversational style and voice. Model IDs are selected automatically by ORI.
- **Voice & Audio:** microphone/speaker selection, device scan, wake word, push-to-talk, morning brief and Windows startup.
- **Appearance:** choose the terminal signal accent. The black/green terminal surface remains the product identity.
- **System:** choose percentages, mini graphs or both for CPU/memory/temperature. Temperature requires a real exposed hardware sensor.
- **Phone Remote:** create an expiring QR pairing link and copy the local dashboard link.
- **About:** version, release/update status and terms. Automatic updates remain Coming Soon until release repository and signing configuration are connected.

There is no Firebase Web API field, browser configuration page, visible integration catalogue, privacy dashboard or copy-diagnostics button in ordinary Settings. Continue with Google and email OTP appear on first-run as Coming Soon; guest mode works.
