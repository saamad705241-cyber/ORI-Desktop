# Security policy

- Never report, upload or commit API keys, pairing secrets, TLS private keys, Google OAuth tokens or personal memory files.
- Phone remote is intended for a trusted private LAN and uses one-time pairing credentials. Do not expose its port to the public internet without a separate security review.
- Screen monitoring is off by default and may only start after an explicit user request. The SCREEN access indicator remains active while frames are shared with Gemini Live.
- Microphone, speaker, screen, camera, keyboard, mouse, browser, file, system and network activity are reflected by live access indicators where ORI controls the action.
- Report vulnerabilities privately to the repository owner rather than posting exploit details in a public issue.
