ORI 3.5.0 / SYSTEM INFORMATION

Purpose: ORI is a personal voice-and-text desktop assistant for supported research, file understanding and user-approved actions on the connected computer.

Current state: Enhancement build. Build date: 11 November 2026. Account sign-in and automatic updates are coming soon.

Runtime: ORI 3.5.0 is the application/runtime identity. This build's live language and voice features use a configured Google-hosted model; ORI is not a claim of a separately trained foundation model.

Capabilities: The mobile dashboard can send text commands, capture voice input, transfer supported files and control wake/interrupt actions. Results depend on actual desktop tools, permissions and connectivity.
